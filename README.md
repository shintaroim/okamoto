# 岡本武司氏 ビジネスプロデュース＆ブランディングプロジェクト

元箱根駅伝 早稲田大学競走部主将・岡本武司（おかもっちゃん）氏のセカンドキャリア支援、ポートフォリオ構築、および収益化ビジネスモデル企画プロジェクトの全データ一式です。

---

## 📂 フォルダ構成と概要

```text
おかもっちゃん/
├── 01_完成成果物_PDF/               # クライアント提示・印刷・共有用の完成版PDF資料
├── 02_企画・原稿ドキュメント/         # 企画原案、プロフィール、プロンプト等のMarkdown/テキスト
├── 03_Webサイトプロトタイプ/         # 実際にブラウザで動かせるインタラクティブWebプロトタイプ
├── 04_ツール・自動生成スクリプト/     # 資料PDF・画像キャプチャ等を生成したPythonスクリプト群
├── 05_作業中間データ・プレビュー/     # レンダリング用HTMLやスライドプレビュー画像
├── index.html                      # ルートからWebプロトタイプを即座に開くリダイレクト用ファイル
└── README.md                       # 本ファイル（プロジェクト全体ガイド）
```

## 🌐 03. Webプロトタイプの体験方法

本プロジェクトで構築したWebプロトタイプは、ローカルPCのブラウザで直接動作します。

- **起動方法**:  
  `03_Webサイトプロトタイプ/prototype/index.html` をダブルクリック（またはChrome等で開く）してください。
- **特徴**:  
  画面最上部に **プロトタイプ・スイッチャーバー（PROTOTYPE BAR）** が組み込まれており、以下の4画面を1クリックで切り替え可能です。
  1. **総合LP (`index.html`)**: ファーストビュー、実績、サービス一覧、お問い合わせ
  2. **アスリート＆アート ポータル (`portal.html`)**: 作品ギャラリー、活動報告、最新トピックス
  3. **ランニング・アカデミー (`academy.html`)**: 指導プログラム、箱根駅伝メソッド、料金プラン
  4. **公式ストア・作品販売 (`shop.html`)**: 原画・受注制作オーダー・公式グッズEC
