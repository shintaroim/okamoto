# 人物分析＆魅力的なプロフィール作成プロンプト集

対象人物の限られた情報やSNS・Webリンクから、**「ドラマチックな経歴・強み・魅力的なプロフィール文章」**を構造化して引き出すための汎用プロンプトです。

---

## 1. そのまま使える完成版プロンプト

```markdown
# 目的
提供された人物情報およびWeb上の関連情報をリサーチ・分析し、その人物の人生ストーリー、強み、魅力が最大限に伝わる構造化されたプロフィール情報を作成してください。

# 対象人物の情報
- 氏名（本名 / 活動名 / 愛称）：[ 例: 岡本武司 / 瑞司 / おかもっちゃん ]
- 主な肩書・活動：[ 例: 鉛筆画家、元高校教師、ラガーマン ]
- 参考URL / SNSリンク：
  - [URL 1: SNSやWebサイトなど]
  - [URL 2]
- その他メモ・キーワード：[ 例: 50代から絵画を始めた、早大出身、など ]

# 調査・分析の視点
1. **人生の転機・ドラマ（ストーリー性）**
   - どのようなターニングポイント（挫折、決断、転身、新たな挑戦）を経て現在に至るか？
2. **唯一無二の強み・価値観（コア・コンピタンス）**
   - 単なるスキルの羅列ではなく、これまでの経歴の「掛け算」から生まれる独自の強みや魅力は何か？
   - どのような理念やメッセージ（モットー、哲学）を持っているか？
3. **周囲への影響・人柄**
   - 顧客、生徒、ファン、周囲の人々からどのような存在として慕われているか？

# 出力フォーマット
以下の構成でMarkdown形式にて出力してください。

---

## 1. 基本プロフィール
- 氏名 / 活動名 / 愛称
- 主な肩書
- モットー / 活動理念
- 公式リンク集

## 2. ドラマチックな経歴・人物像
- 人生を象徴するテーマ・キャッチコピー
- 青年期・壮年期・現在などのターニングポイントを時系列またはストーリー仕立てで整理

## 3. 主な特徴と強み（コア・コンピタンス 3〜4点）
- 経歴の掛け合わせや独自性（例: 「教育 × アート」「常識を超える突破力」など）
- 人柄やコミュニケーションの特徴

## 4. 用途別プロフィール文章
- **【用途A】Webサイト・SNS・パンフレット用（300〜400字程度）**
  - 第三者視点で信頼感と親しみやすさ、情熱が伝わる文章
- **【用途B】講座・講演・イベント登壇紹介用（箇条書き型）**
  - 参加者・聴講者にとってのベネフィットや魅力がひと目でわかる箇条書き
```

---

## 2. プロンプト作成時のポイント・カスタマイズ方法

### ①「異色の経歴（掛け算）」を際立たせたい場合
プロンプトの「調査・分析の視点」に以下を追加します：
```markdown
- **キャリアの掛け算（シナジー）の抽出**
  過去のキャリア（例：体育教師・ラグビー）と現在の活動（例：鉛筆画）がどのように融合し、他の同業者にはない独自の価値を生み出しているかを特に掘り下げてください。
```

### ② ビジネス・採用・ブランディング向けに寄せたい場合
出力フォーマットの「4. 用途別プロフィール文章」を以下のように変更します：
```markdown
- **【用途A】LP（ランディングページ）・講師紹介用（実績重視）**
- **【用途B】プレスリリース・メディア取材用（客観性・社会的意義重視）**
- **【用途C】SNSプロフィール用（140〜160文字程度の要約）**
```

### ③ 情報が少ない人物を調べる場合
リサーチ指示として以下を冒頭に添えると精度が上がります：
```markdown
※提供情報が断片的な場合、名前・活動名・関連キーワードを用いてWeb検索を行い、インタビュー記事、過去の報道、SNSの投稿内容などを裏取り・補完しながら分析してください。
```
